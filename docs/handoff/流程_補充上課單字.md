當 Sharon 在 [[project_phonics_flashcard]]（英雄學習平台）語境下說「補充上課單字」＋一份英文單字清單，直接照下面流程做，不用每次都問：

1. **確認單字庫**：在 `src/data/words.ts`（自然發音）和 `src/data/sightWords.ts`（重要單字）用 grep 檢查清單裡每個字是否已存在（不分哪個庫，只要任一邊有就算存在）。
   - 已存在的字（不管在哪個庫）：不重複加入，記下對應的 id（如果兩個庫剛好都各有一筆舊的，屬於歷史遺留，見下方 2026-08-21 更新，不用去動它，但步驟 2 只取 words.ts 那個 id）。
   - 不存在的字：**優先加入 `words.ts`（自然發音庫）**，判斷最適合的 phase/subPhase，比照鄰近同類單字的欄位風格新增一筆（id/word/kk/zh/zhuyin/en/sentence/emoji/phase/phaseLabel/subPhase/subPhaseKey/category/highlight 都要填），插入到對應分類區塊裡。只有真的抓不到任何自然發音規律（例如 pizza、homework、laundry 這種和發音階段無關的常見名詞）才退回放 `sightWords.ts` 的 NN 分類。**不要同一個字兩邊都各加一筆**——這是 2026-08-21 Sharon 明確要求的規則，目的是讓單字庫不要有重複的單字。
   - 加完後跑 `npx tsc --noEmit` 確認沒有型別錯誤，並確認沒有重複 id。
2. **加入本週單字**：整份清單裡的字（不管是原本就有的還是新加的）**全部**加入本週單字（這點沒變），但如果某個字兩個庫都各有一筆（歷史遺留的舊重複），**只加 `words.ts`（自然發音庫）那個 id，不要把 `sightWords.ts` 那個也加進去**——這是 2026-08-21 更新的規則，避免本週單字清單裡同一個字顯示兩次。
   - 本週單字不是寫在程式碼裡，是存在 Vercel KV，透過正式站的 `/api/sync` 這個 API 讀寫（`GET` 拿目前狀態，`POST` 整包狀態回去，last-write-wins by `updatedAt`）。
   - 流程：`curl GET https://phonics-flashcard.vercel.app/api/sync` 抓目前狀態 → 算出本週的週一日期當作 week key（格式 `YYYY-MM-DD`，用 `curriculum.ts` 的 `mondayOf` 邏輯，週一到週日為一週）→ 把這次清單對應的所有 id 併入 `curriculum[weekKey]`（用 Set 去重，其他已存在的字不要動）→ 其餘欄位（progress、hanziWords、klotskiProgress...）原封不動 → `updatedAt` 設成現在的 timestamp → `POST` 整包回去 → 用 `GET` 再驗證一次伺服器上的週字數量。
   - 這是直接動到正式站的即時雲端資料（Sharon 兒子真實的學習進度），操作前務必先 GET 拿最新狀態再合併，避免蓋掉其他裝置剛寫入的東西。

**Why**：Sharon 明確選擇「整份清單都加入本週單字」而非「只加新補充的字」，因為清單代表這週要教的字，不管單字庫裡原本有沒有，都要在本週單字出現。

**2026-08-21 更新（重要修正）**：Sharon 發現本週單字清單裡有 15 組字（play/red/hot/ten/bed/leg/top/blue/flower/fly/good/sun/grass/green）同一個字出現兩次，根因是這些字在 `words.ts` 和 `sightWords.ts` 裡本來就各存了一筆（平台早期兩套系統各自建立時留下的歷史重複，不是這個補充流程造成的新重複），而先前的規則是「兩邊都存在就兩個 id 都加進本週單字」。Sharon 因此要求：① 之後新增進單字庫的字盡量只放 `words.ts`（自然發音庫），不要兩邊都加；② 「加入本週單字」如果遇到某個字兩邊都有，只取 `words.ts` 那個 id。**不要求回頭清理/刪除資料庫裡既有的重複條目**，只是「以後」加入本週單字時只取一個 id——這點如果 Sharon 之後沒特別說，不要主動去刪 `sightWords.ts` 裡的舊重複條目。
- 例外：像「pen」這種同拼法但不同意思的字（筆 vs 動物圍欄）不算重複，兩個 id 都可以加，因為代表的是兩張不同的卡。

**How to apply**：只有在明確講「補充上課單字」時套用這個完整流程；如果只是單純問「確認這些字在不在單字庫」（沒提到本週單字），只做步驟 1，本週單字要等 Sharon 額外說才處理（可參考 [[project_phonics_flashcard]] 之前的對話模式）。
